# CC Switch 界面功能记录

## Image_2026-08-23_032551_604.png

- 页面层级为“设置 > 路由”，顶部用横向分段导航切换通用、路由、认证、高级、使用统计和关于。
- 路由页先展示本地路由服务状态，并提供主页面显示开关与路由总开关。
- 路由启用区按应用独立控制，当前示例包含 Claude、Codex、Gemini、Grok Build，并以开关明确区分启用/停用。
- 服务地址作为可复制的只读输入展示；修改地址或端口后需要重新启动路由服务才能生效。
- “使用中”区域显示不同应用当前选中的路由目标或模型映射，便于核对实际生效配置。
- 提供“记录请求用量”开关，将路由请求的用量与状态写入本地统计数据库。
- 整体采用深色设置页、分段导航、分组面板和右侧开关，信息层级清楚，运行状态与配置操作分离。

## Image_2026-08-23_032618_318.png

- 路由页下半部分继续保留“记录请求用量”开关，使运行统计与路由配置处于同一控制面。
- 故障转移队列按应用分组；Claude 与 Codex 各自维护带序号的 Provider 优先级列表。
- 当前生效项同时使用蓝色选中背景和“使用中”文字标记，不只依赖颜色表达状态。
- 每个 Provider 在行尾显示健康状态，示例包括正常、降级和熔断，可直接判断是否参与后续请求。
- 队列下方汇总活跃连接、总请求数、成功率和运行时间，便于在修改策略时同步观察服务表现。
- “自动故障转移”作为可折叠配置区，与上方只读运行态区分开，避免策略选项持续占用页面空间。

## Image_2026-08-23_032635_677.png

- 自动故障转移区提供“在主页面显示故障转移开关”，把策略可见性作为独立设置。
- 使用应用分段控件切换 Claude、Codex、Gemini、Grok Build，各应用拥有自己的故障转移队列。
- 队列编辑区有自动故障转移开关，并用说明明确“先选 P1，失败后按顺序尝试下一个供应商”的执行规则。
- 供应商通过下拉选择加入队列，旁边用加号图标提交；队列项显示优先级与名称，并提供逐项移除按钮。
- 编辑面板将策略说明、添加控件和队列列表分层排列，适合反复调整供应商顺序。

## Image_2026-08-23_032655_056.png

- 队列编辑区明确说明队列顺序与首页供应商列表顺序一致，支持在首页拖拽调整优先级。
- 多供应商故障转移的行为规则直接写在页面中：按优先级依次尝试，连续失败达到阈值时由熔断器暂时跳过该供应商。
- “重试与超时设置”将最大重试次数与失败阈值并列展示，并在字段下方给出范围和含义说明。
- “超时配置”继续细分流式首字节超时、流式静默超时和非流式超时，说明不同请求阶段需要独立控制。
- 该页的参数配置强调可解释性，字段旁同时呈现单位、范围和对故障转移行为的影响。

## Image_2026-08-23_032713_334.png

- 重试参数包括最大重试次数和失败阈值；每个输入下方标注允许范围或建议值。
- 超时参数按流式首字节、流式静默、非流式三类拆分，并明确各自的秒数范围、默认值和“填 0 禁用”等特殊语义。
- 熔断器参数包括恢复成功阈值、恢复等待时间、错误率阈值和最小请求数，覆盖半开恢复、时间窗口和统计样本下限。
- 配置面板底部固定提供“重置”和高强调的“保存”操作，避免参数填写后缺少明确提交入口。
- 下方还有可折叠的“整流器”配置区，说明路由器把故障转移与协议适配作为两个独立能力管理。

## Image_2026-08-23_032732_949.png

- “整流器”面板以“自动修复 API 请求中的兼容性问题”为定位，并提供总开关；关闭后所有整流规则统一停用。
- 请求整流按具体兼容问题拆分为 Thinking 签名、Thinking 预算、不支持图片降级、纯文本模型预判，每项都有单独开关与行为说明。
- 规则说明直接写出触发条件、改写动作和必要时的重试行为，便于用户理解自动修复不会无条件修改请求。
- 另外提供 Bedrock 请求优化器分组，说明只对 Bedrock 供应商生效，并细分 Thinking 优化和 Cache 注入。
- Cache 注入项展示了固定时间断点和降低重复用量计费的目标，说明性能/成本优化的可见收益。

## Image_2026-08-23_032812_637.png

- 使用统计页提供供应商图标筛选，并可按来源、模型、自动刷新间隔和日期范围过滤。
- 顶部摘要把真实消耗 Tokens、总请求数、总成本独立呈现，同时拆分新增输入、Output、创建、命中和缓存命中率。
- 费用与用量不是混为一个指标，而是分别展示数量和金额，适合核对成本。
- “使用趋势”用时间序列图同时呈现用量曲线和成本曲线，并标注当前日期和双侧刻度。
- 统计页适合持续监控，筛选和刷新控件集中在标题右侧，主体区域保留给关键指标和趋势。
### Image_2026-08-23_032829_455.png

- 使用统计页提供时间序列图，图例区分成本、缓存创建、缓存命中、输入和输出。
- 下方有三种统计视图：请求日志、Provider 统计、模型统计；当前选中请求日志。
- 请求日志支持供应商筛选和日期范围筛选，筛选控件带下拉箭头和日期图标。
- 日志表按时间、供应商、计费模型、输入、输出、总成本、用时/首字、状态、来源展示。
- 计费模型列同时展示原始模型到实际路由模型的映射；成本可能显示具体金额或未定价。
- 状态用颜色区分成功结果，来源字段标识为代理转发类来源；长列表需要支持纵向滚动。
### Image_2026-08-23_032846_941.png

- 使用统计页的趋势图采用双纵轴：左侧展示 Token 量级，右侧展示成本金额；时间轴按小时推进，并保留成本、缓存创建、缓存命中、输入、输出图例。
- 统计区域提供请求日志、Provider 统计、模型统计三个切换视图；当前 Provider 统计使用带图标的分段标签突出选中态。
- Provider 汇总表按供应商展示请求数、Tokens、成本、成功率和平均延迟，便于横向比较各上游的用量、费用与质量。
- 汇总数据覆盖有请求但无 Token 或费用、成功率为零等边界情况，不隐藏异常供应商。
- 页面下方提供可折叠的“成本定价”管理区，用于维护各模型的 Token 计费规则。
- 另有可折叠的 Codex 用量维护区，可从本地 rollout 日志重新构建 Codex 会话用量。
### Image_2026-08-23_032900_913.png

- 模型统计视图与请求日志、Provider 统计并列切换，选中态使用蓝色背景和统计图标。
- 趋势图支持悬停查看指定时间点，垂直参考线和数据点同步标示成本、Token 等系列值；图例仍保留各指标颜色区分。
- 模型汇总表按模型展示请求数、Tokens、总成本和平均成本，支持长列表滚动。
- 模型名称可能是标准模型、供应商完整限定名或自定义路由模型名，需要完整显示并允许较长文本。
- 统计表保留请求数大但 Token/成本为零的记录，平均成本以固定小数位展示，避免把零值误认为缺失。
### Image_2026-08-23_032921_756.png

- 成本定价面板可展开或收起，用于集中管理模型 Token 计费规则。
- “计费默认配置”按应用设置默认倍率与计费模式，覆盖 Claude、Codex、Gemini、Grok Build 等应用，并提供统一保存操作。
- 默认倍率使用数字输入框，计费模式使用下拉选择；当前模式以返回模型为计费依据。
- 支持自动同步外部模型定价数据，显示开关状态、上次同步状态和常用模型启用状态。
- 定价文件保存在本地；界面提供打开目录、重新加载文件、选择模型和立即同步操作。
- 下方模型定价表可逐项维护模型、显示名称、输入成本、输出成本、缓存命中成本和缓存创建成本，并提供新增模型入口。
### Image_2026-08-23_032940_110.png

- 模型 Token 成本配置区以表格呈现，顶部提供“添加”按钮。
- 表格列包括模型标识、显示名称、输入成本、输出成本、缓存命中和缓存创建成本，成本单位为每百万 Token。
- 模型标识使用等宽字体，显示名称用于可读化展示；长模型标识需要保持可辨识性。
- 每行提供编辑和删除图标操作，适合对单个模型定价进行维护。
- 价格字段以货币格式展示，缓存相关单价与输入/输出单价分开配置，便于准确计算不同 Token 类型的费用。
### Image_2026-08-23_033038_058.png

- Skills 管理页以长列表展示已安装技能，顶部提供检查更新、从备份恢复、从 ZIP 安装、导入已有技能和发现技能入口。
- 页面用按应用分类的数量徽标汇总已安装技能，包含 Claude、Codex、Gemini、Grok Build、OpenCode、Hermes 等应用分类。
- 列表支持按技能名称、描述或仓库搜索；每行展示技能名、来源标识和一行描述摘要。
- 每个技能行右侧有多个应用启用/关联图标，可按应用单独配置技能适用范围；图标状态需要有明确的选中与未选中差异。
- 长描述在列表中单行截断，列表整体可滚动；顶部操作适合使用图标加文字按钮，便于执行安装、恢复和导入流程。
### Image_2026-08-23_033110_034.png

- Skills 管理页另有“仓库”和 `skills.sh` 两个来源标签，当前展示仓库技能市场。
- 顶部提供刷新和仓库管理入口；搜索框支持按技能名称或仓库名称查找，旁边有仓库范围与分类筛选下拉框。
- 技能以三列网格卡片展示，每张卡片包含技能名、仓库路径、仓库徽标和描述摘要。
- 卡片底部提供查看入口和绿色安装按钮，安装按钮带下载图标；安装动作需要有进行中、成功和失败反馈。
- 描述摘要支持多行但需要限制高度，过长内容截断；卡片网格在窄屏下应降为更少列数以保持操作可达。
### Image_2026-08-23_033131_088.png

- Skills 管理页切换到 `skills.sh` 来源后，搜索框可输入关键词，右侧提供明确的“搜索技能”按钮。
- 搜索结果仍以三列网格卡片展示，卡片显示技能名、仓库归属和下载量徽标，帮助用户比较热门程度。
- 每张结果卡片保持统一的查看与绿色安装操作区，查看使用外部链接图标，安装使用下载图标。
- 结果可能来自不同组织和仓库，同名技能也可能重复出现，因此仓库名称和下载量应与技能名同时展示。
- 当前截图展示关键词搜索结果且卡片描述较简洁；列表仍需支持纵向滚动和响应式降列。
### Image_2026-08-23_033146_102.png

- “管理技能仓库”页提供添加仓库表单，填写仓库 URL 和分支后可新增仓库。
- 仓库 URL 支持 `owner/name` 简写或完整托管平台 URL；分支输入有默认值，表单需提供清晰的校验反馈。
- 已添加仓库以纵向列表展示仓库标识、分支和识别到的技能数量。
- 每个仓库行提供打开仓库和删除图标操作；删除属于有影响的操作，应有确认与失败反馈。
- 仓库列表适合全宽排列并支持纵向滚动，添加区域与已有仓库区域分开，便于扫描管理。
### Image_2026-08-23_033206_571.png

- 提示词管理页按应用展示，当前为 Claude 提示词管理；顶部显示提示词总数和已启用提示词名称。
- 页面提供新增提示词入口，搜索框支持按名称、描述或内容检索。
- 提示词以单行卡片/列表项展示，包含启用开关、名称和描述摘要。
- 每条提示词提供编辑和删除图标操作；启用状态用绿色开关直观表示。
- 空白区域较多时保持简洁布局，列表增长后应支持纵向滚动；删除和编辑操作需要维持状态反馈。
### Image_2026-08-23_033227_469.png

- 会话管理页采用左中右三栏布局：左侧会话列表，中间会话详情与对话记录，右侧对话目录。
- 左侧显示会话总数、当前选中态、最近活动时间和会话名称；顶部提供批量选择/排序、搜索、应用筛选和刷新等工具。
- 中间顶部展示会话所属应用、名称、时间、工作目录和会话标识摘要，并提供复制信息和删除会话操作。
- 对话记录按消息卡片排列，区分用户消息与本地命令输出；右侧目录按序号列出可跳转的对话片段，适合长会话快速定位。
- 长文本和命令内容需要可滚动、可复制且保持等宽/层级结构；删除会话属于高影响操作，需要确认与结果反馈。
### Image_2026-08-23_033246_446.png

- MCP 服务器管理页顶部提供导入已有配置和添加 MCP 入口，并显示已配置服务器总数。
- 页面按应用显示已配置数量徽标，覆盖 Claude、Codex、Gemini、Grok Build、OpenCode、Hermes 等分类。
- 搜索框支持按 MCP 名称、描述、标签或命令检索。
- 服务器以全宽列表展示名称和描述摘要；部分条目带外部链接图标，表示可打开其来源或详情。
- 每行右侧提供按应用启用/关联的图标组，适合精细控制不同应用是否加载该服务器；图标状态需要清楚区分。
- 列表需支持长内容滚动，并为导入、新增、编辑、删除等配置操作提供状态反馈与必要确认。
### Image_2026-08-23_033301_565.png

- 新增 MCP 页先选择 MCP 类型，提供自定义、fetch、time、memory、sequential-thinking、context7 等快捷类型标签。
- 表单要求填写唯一 MCP 标题，并可填写显示名称；字段需要明确必填标识与重复校验。
- “启用到应用”使用复选框，可分别选择 Claude、Codex、Gemini、Grok Build、OpenCode、Hermes。
- 附加信息为可折叠区域，适合放置可选元数据或补充配置。
- 页面提供完整 JSON 配置编辑区，支持配置向导和格式化操作；配置内容使用代码编辑器样式并保持可复制性。
- 底部提供添加提交按钮；类型快捷标签应能填充合理模板，JSON 与表单字段之间需要保持一致。
