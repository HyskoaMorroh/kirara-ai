# Kirara WebUI source

This directory is based on `kirara-ai-webui` 0.1.1-beta.3 from the
[DarkSkyTeam/kirara-webui](https://github.com/DarkSkyTeam/kirara-webui) project.
The upstream project is MIT licensed. Local changes keep the upstream UI intact
and add the BackupCard settings tab required by this Kirara AI distribution.
