备份与恢复

导出或恢复完整实例数据。此页面由后端直接提供，不依赖 WebUI 版本。

1. 登录

备份接口需要管理员身份。若你已在 WebUI 登录过，令牌会自动复用，无需重复输入。

2. 导出完整备份

导出内容：系统与 Web 设置、模型与机器人配置、工作流、触发规则、数据库、记忆、媒体、插件、字体及自动探测状态。

备份包含明文凭据：模型 API Key、机器人 Token、Web 密钥与密码哈希都在里面。 请只保存到你信任的本地位置，切勿提交到 GitHub、推进 Docker 镜像或发给他人。

3. 导入并恢复

先「检查」确认备份包结构与内容，再「恢复」写入。恢复前会自动在 data/backups/ 生成回滚包；校验或写入失败时原数据保持不变。

恢复成功后必须重启服务，配置、工作流与 MCP 连接才会重新加载。
